Autoware's Open AD Kit is now live on [Arm Learning Paths](https://learn.arm.com/learning-paths/automotive/openadkit1_container/). Working through the path teaches the fundamentals of the Open AD Kit and lets you run the latest demo on your own machine.

The path covers the SOAFEE architecture and its role in enabling shift-left practices for streamlined autonomous driving development, how to operate the Autoware Open AD Kit simulation environment, how to deploy containerized workloads with Docker on Arm Neoverse processors in both cloud and on-premise setups, and how to explore advanced configurations and future enhancements. To run the demo, you'll need an Arm Neoverse cloud instance or a local Arm Neoverse Linux machine with at least 16 CPUs and 32GB of RAM, plus familiarity with Docker and Docker Compose.
